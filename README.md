# Industrial Equipment Monitoring System

## About

This project is a software system for monitoring industrial equipment.

The system will collect equipment data such as temperature, pressure,
and vibration and detect abnormal conditions.

## Goal

The goal is to build a real-world software project while learning
C++, backend development, databases, Git, GitHub, and testing.

## Planned Features

- Store equipment information
- Store sensor readings
- Monitor temperature, pressure, and vibration
- Detect abnormal sensor values
- Generate alerts
- Maintain equipment status
- Store monitoring data
- Add tests
- Later connect the system to a database/API
